# KP-流程-001 待办与消息转移

## 识别信号

需求涉及**处理人变更**（指派 / 转移 / 代办）或**待办、消息、通知**。

线索词：指派、转派、代办、待办、我的待办、通知、抄送、消息提醒、处理人

## 典型测试点

1. 变更后**新处理人**获得待办 —— **每个入口各一条**（审批流待办 / 首页待办）
2. 变更后**原处理人**失去待办 —— 同上，每个入口各一条
3. 变更动作的留痕（时间、操作人）
4. 是否影响流程推进 / 节点状态
5. 权限边界：无权限者不可操作
6. 边界：无可变更对象 / 流程已结束 / 节点已处理

## 典型澄清问题

1. 待办列表一共有几个入口？（须逐入口对称验证）
2. 变更后原处理人是否保留查看权限？
3. 变更是否通知相关人员？通过什么渠道？
4. 流程结束后是否还可变更？
