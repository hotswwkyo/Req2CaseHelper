# KP-时效-001 时间窗口与倒计时

## 识别信号

出现**倒计时、冷却、重发间隔**。

线索词：倒计时、冷却、间隔、X 秒后可重发、禁止重复提交

## 典型测试点

1. 启动：{触发动作} 后启动，时长 = {N} 秒
2. 期间操作被禁用（置灰、点击无副作用、不重复触发）
3. 归零后可再次操作，并重新开始倒计时
4. 精度与边界：{N-1} / {1} / {0} 秒的显示与可点击状态
5. 离开 / 重进页面后倒计时状态是否延续
6. 多端 / 多标签页下倒计时是否共享

## 典型澄清问题

1. 倒计时是前端计时还是后端计时？刷新页面是否重置？
2. 多端登录时倒计时是否共享？
3. 倒计时期间是否可以强制重发（如特定角色）？
