# KP-权限-001 权限与角色差异

## 识别信号

出现**角色、权限、可见性**（"仅 X 可操作"、"按角色展示"）。

线索词：角色、权限、仅XX可、按角色、可见、隐藏、只读、数据范围、所属公司

## 典型测试点

1. 逐角色核对：{角色A} 可见/可操作、{角色B} 不可见/不可操作 —— **逐角色独立用例，禁止合并**
2. 无权限时的表现（隐藏 / 置灰 / 点击提示）
3. 越权：直接访问 URL 或接口是否被拦截
4. 数据范围：{本人 / 本部门 / 本公司} 过滤正确
5. 权限变更的生效时机
6. 边界：多角色叠加、无角色

## 典型澄清问题

1. 涉及哪些角色？各自的可操作范围是什么？
2. 无权限时是隐藏入口还是置灰提示？
3. 数据可见范围如何界定（本人 / 本部门 / 本公司）？
4. 权限变更是否需要重新登录生效？
