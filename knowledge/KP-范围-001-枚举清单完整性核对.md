# KP-范围-001 枚举清单完整性核对

## 识别信号

需求给出**适用对象清单**——"涉及以下 N 处"、"以下类型需调整"、"以下除外"。

线索词：涉及以下、以下几处、以下类型、除…外、以下除外、清单、如下

> 清单本身不是独立功能，但**必须逐项核对防漏配**，因此单列为一个知识点。

## 典型测试点

1. 清单内**逐项**核对，每项独立验证（**禁止抽样**）
2. 清单外对象**不应被改动** → {排除项} 保持原行为
3. 清单条目数 vs 系统实际同类对象数（是否还有未列出的同类）
4. 清单含"其余 / 等"等模糊表述 → 标 `[待澄清]`
5. 清单项的**位置 / 顺序**要求（如"置于 X 之前"）

## 典型澄清问题

1. 清单是否完整？是否还有同类对象未被列出？
2. 清单外的对象是否确认不受影响？
3. "其余 / 等"具体指哪些？
4. 清单项的先后顺序是否有要求？
