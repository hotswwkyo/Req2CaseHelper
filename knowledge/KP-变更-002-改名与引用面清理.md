# KP-变更-002 改名与引用面清理

## 识别信号

需求要求替换文案 / 名称 / 字段名（"X 改为 Y"）。

线索词：改名、更名为、改为、替换、统一为、抬头、文案调整

## 典型测试点

1. 逐入口核对：{发起 / 新增} / {展示 / 详情} / {编辑} 全链路一致
2. 旧名 / 旧文案**无残留**
3. 存量历史记录中的旧名处理（→ 联 `KP-变更-001`）
4. 其他引用面：模板变量 / 导出文档 / 消息与待办名称
5. 仅替换清单列明处，清单外不受影响

## 典型澄清问题

1. 改名涉及哪些页面 / 入口？是否已列全？
2. 存量历史记录中是否也要改名？
3. 是否影响已生成 / 已下载的文档？
4. 是否涉及导出模板、消息通知名称？
