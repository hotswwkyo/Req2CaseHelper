# KP-状态-001 状态机

## 识别信号

出现**枚举状态**描述（"状态为 X 时"、"状态变更为 Y"），或需求给出了状态清单。

线索词：状态、待XX、已XX、进行中、已完成、已关闭、已作废、启用、停用

反例（不命中）：把"状态"当作纯粹的数据字段（只存储不驱动行为）时，按 KP-数据-001 处理。

## 典型测试点

1. 合法迁移：{状态A} → {状态B} 成功
2. 非法迁移：{状态A} → {状态C} 被拦截
3. **各状态下的可执行操作矩阵** —— 逐状态 × 逐操作，每个组合独立用例，**禁止合并**
4. 状态互斥：{同类对象} 只能有一个处于 {状态}
5. 终态：进入 {终态} 后全部操作不可用
6. 状态筛选 / 统计：结果正确；无数据时 {空态表现}

## 典型澄清问题

1. 状态枚举的完整清单是什么？是否存在中间态？
2. 每个状态下允许哪些操作？
3. 状态是否可回退？回退是否留痕？
4. 已关闭 / 已作废后是否还可以查看？
