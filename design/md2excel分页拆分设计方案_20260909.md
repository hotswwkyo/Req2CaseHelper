# md2excel 分页拆分设计方案（v4）

> - 日期：2026-09-09
> - 状态：**已实现**（2026-09-09，见 `md2excel.py` 与技能文档）
> - 修订记录：v3——旧记录为测试数据，**不做迁移兼容**（移除原「加载迁移」方案，load 结构不符视为空）；v4——默认分页大小由 10 改为 90。实现补充：裸 `--split` 经 argv 预处理自动补默认值，防止 argparse 把后续文件参数误当分页值。
> - 关联代码：`.github/skills/md2excel/scripts/md2excel.py`
> - 涉及技能文档：`.github/skills/md2excel/SKILL.md`、`.github/skills/zt-import/SKILL.md`

## 一、目标与背景

- 当一套测试用例行数较多时（受禅道单文件导入行数限制 / 便于分块评审），把原来「一个 MD → 一个 Excel」拆成「一个 MD → 多个 Excel」。
- **两种拆分模式**：① 按固定条数分页（类似翻页，超出 N 条就落下一文件）；② 按「所属模块」拆分（每个模块一个文件）。
- **默认不拆分**：不带新参数时，行为与现状 100% 一致（命名、记录、样式均不变），保证向后兼容。

## 二、影响设计的现状要点

1. `convert_rows()` 已支持把 MD 的「所属模块」映射进 Excel（仅在 `--with-module` 时），当前默认「所属模块」列为空。
2. `process_md_file()` 把 MD 内多张用例表按出现顺序**合并成单个 `all_rows`** → 写入 1 个 xlsx。
3. 记录文件 `md2excel_record.json` 目前是**一一对应**：`{"md": ..., "excel": ...}`；本次修订改为 `excel` → **列表**（见第五章）。现有记录为**测试数据，不做迁移兼容**。
4. `zt_import.py` 允许一次传多个 `-tcfile`，并对每个文件逐行设置**同一个** `-mpath`（由用户给出，Excel 内的「所属模块」列仅是信息列，不起模块归属作用）。

## 三、CLI 变更草案（向后兼容）

```
# 新增两个互斥参数（不传则与今天完全一致）
--split [N]          # 按条数分页，每个文件最多 N 条用例（N≥1，缺省 N=90）
--split-module       # 按"所属模块"拆分，每个模块一个文件（等价自动开启 --with-module）
```

- `--split` 与 `--split-module` 同时给出 → 报错提示「二选一」。
- `-o/--output`、`--force`、`--with-module` 语义不变；分页文件都写入同一输出目录。
- 默认分页大小用常量 `DEFAULT_PAGE_SIZE = 90`（便于后续调整）。

## 四、命名规则

| 场景 | 输出名 |
|---|---|
| 未拆分（现状） | `test_cases_X_20260903.xlsx`（不变） |
| 按条数分页、≥2 页 | `test_cases_X_20260903_001.xlsx`、`_002.xlsx`…（0 填充保持字典序=页码序） |
| 按模块拆分、≥2 个模块 | `test_cases_X_20260903_<模块>.xlsx` |
| 拆分后实际只有 1 个文件 | **沿用无后缀原名**（避免无谓改名） |

关键规则：

- **只有当结果 ≥2 个文件时才加后缀**；1 个文件时文件名与今天完全相同。
- 模块名需做**文件名安全化**：`/`、`\`、`:`、`*`、`?`、`"`、`<`、`>`、`|` 及首尾空格 → 替换为 `_`；模块路径如 `/系统管理/用户管理` 变为 `系统管理_用户管理`。
- 若两个模块安全化后重名（或与既有文件冲突），追加 `_2`、`_3` 消歧。
- 按条数分页时若尾部不足 N 条，照常写成最后一个小文件（**不丢弃**）。

## 五、记录结构（本次修订：`excel` → 列表）

`md2excel_record.json` 数据结构由「每个 md 一条、单 excel 字符串」改为「每个 md 一条、excel 列表」：

```json
// 新结构
[
  { "md": "testcases\\test_cases_X_20260903.md",
    "excels": ["testcases\\test_cases_X_20260903_001.xlsx",
               "testcases\\test_cases_X_20260903_002.xlsx"] }
]
```

配套改动：

- **旧数据处理（本次修订）**：现有 `md2excel_record.json` 为测试数据，**不做迁移兼容**；`load_record()` 读到旧格式（含 `excel` 键）或结构不符时直接视为空记录。实现阶段可直接重置/删除现有记录文件。
- **更新语义（本次修订）**：每次成功处理某 MD 后，将其 `excels` **替换为本次实际生成的输出集合**——记录即"最近一次输出快照"，避免旧分片残留造成"以为已转换"的误判。未拆分（单文件）时列表只有一个元素，语义与旧版一致。
- **已转换判断**：`is_already_converted(md, excel_path)` 改为查询该 md 的 `excels` 列表成员。
- `--force`：清空记录重来（现状不变）。
- **独立去重不受影响**：zt_import 的去重文件 `testdata/imported_testcase_files.txt` 是按 excel 文件路径逐行记录，与本记录结构无关。

## 六、核心处理逻辑（伪码示意，非实现）

```
process_md_file(...):
    all_rows = 合并后的行            # 顺序 = MD 内出现顺序
    if 模式 == 按条数:
        outputs = [all_rows[i:i+N] for i in range(0, len, N)]
        paths   = 命名_页码(...)      # _001/_002
    elif 模式 == 按模块:
        rows = convert_rows(..., with_module=True)   # 需模块值（自动等价 --with-module）
        outputs = 按"所属模块"首次出现顺序分组（空模块归入"未分组"）
        paths   = 命名_模块(...)
    for path, rows in zip(paths, outputs):
        if is_already_converted(md, path): 跳过
        else: write_excel(path, rows)
    update_record(md, paths)   # 替换式：excels = paths
```

要点：

- 每个分片文件都是**独立完整 workbook**：表头重复、样式（微软雅黑 Light、蓝灰表头、列宽、边框）一致 → 任一文件都可单独导入禅道。
- 按模块拆分时**自动启用模块提取**（等价 `--with-module`），否则无从分组；若 MD 内没有「所属模块」列或全部为空 → 提示并退化为单个文件。
- `write_excel()` 本身无需大改，只把「传入的行」从全量变成分片。

## 七、与 zt-import 的协同（本次修订：`-mpath` 不对等，需询问用户）

- **`-mpath` 与文件名/「所属模块」不对等**：MD 或文件名中的「所属模块」（如 `系统管理_用户管理`）只是用例文档的分类名，**不等于**禅道中的真实模块路径（如 `/260528/系统管理/用户管理`）。
- 因此执行 zt-import 时，**必须询问用户给出每个文件（或整批）对应的真实 `-mpath`**，不能从文件名推断、也不自动对等。
- 典型用法：
  - **同一 `-mpath`**：整批分页文件一次导入 → `-tcfile f_001.xlsx f_002.xlsx …`，一个 `-mpath` 应用到全部。
  - **按模块拆分**：若各模块文件对应不同禅道模块 → 分多次导入，每次由用户指定该文件对应的 `-mpath`。
- Excel 内的「所属模块」列仅为信息列（禅道导入预览不按此列分模块）；模块归属由 zt_import 用 `-mpath` 下拉逐文件指定。
- 去重：`imported_testcase_files.txt` 按 excel 路径逐行记录，各分片各自记录、互不影响。

## 八、边界情况清单

1. MD 0 行 / 无可识别表 → 跳过（现状不变）。
2. 空「所属模块」在按模块模式下 → 归入「未分组」文件。
3. 模块名含非法字符/超长 → 安全化 + 消歧后缀。
4. 旧记录为测试数据、不迁移：旧格式/结构不符 → `load_record()` 视为空；实现阶段可重置现有 `md2excel_record.json`。
5. 记录以"最近一次生成的输出集合"为准；旧分片文件残留在磁盘不自动删除（如确需重导由用户删除或依赖 `--force`）。
6. 新拆分文件与旧版已生成的未拆分同名文件并存（只写新路径，不删旧文件）。
7. 页大小 N=1 / N≥总行数 的极端情况。
8. 拆分模式下 `--with-module` 提示语（按条数分页不强制、按模块自动开启）。
9. `--force` 全量覆盖（清空记录）。
